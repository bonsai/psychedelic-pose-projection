評価基準 (Evaluation Criteria)

    評価：十分（骨格・関節の追従精度良好、遅延なし）。
  • エフェクト視認性 (Effect Visibility): 色・残像・波紋などが動きに連動しているか。
    評価：高い（サイケデリックなエフェクトが明確に表示され、動きに合わせて変化）。
  • ダンス映え (Dance Impact): ダイナミクス・リズム感・映像としてのインパクト。
    評価：良好（運動時のダイナミックなエフェクト、リズム感あり）。

Python Code – VLM Evaluation Script


# psuedo-code for VLM evaluation
# 1. Load frames from data/capt_frames/
# 2. Send to tempura-qwen2.5-vl-3b via API
# 3. Parse response (text + image URLs)
# 4. Compute scores per criterion
# 5. Save to data/rec/vlm_evaluation.txt

def evaluate_vlm_frames(frames_dir):
    import requests
    import base64
    from pathlib import Path
    
    MODEL = "tempura-qwen2.5-vl-3b"
    API_URL = "http://localhost:1234/v1/chat/completions"
    
    # Build content with image URLs
    content = [
        {
            "type": "text",
            "text": (
                "このシステムはMediaPipeでポーズを検出し、"
                "骨格や体の動きに応じてサイケデリックなエフェクトを重ねる。"
                "各フレームについて以下の4項目で評価する。"
            )
        }
    ]
    
    for frame_file in sorted(Path(frames_dir).glob("*.jpg")):
        img_data = base64.b64encode(open(frame_file, "rb")).decode()
        content.append({
            "type": "image_url",
            "image_url": {"url": f"data:image/jpeg;base64,{img_data}"}
        })
    
    payload = {
        "model": MODEL,
        "messages": [{
            "role": "user",
            "content": content
        }]
    }
    
    resp = requests.post(API_URL, json=payload)
    result = resp.json()
    
    # Extract score fields (mock keys based on typical VLM response)
    score = result.get("score", {})
    print(f"Overall score: {score.get('overall', 0)}")
    print(f"Breakdown: {score}")
    
    # Save to rec/ directory
    out_path = Path("/mnt/c/Users/0501JP/bons-windows/rec/vlm_evaluation.txt")
    out_path.write_text(result.get("message", ""), encoding="utf-8")
    print(f"Saved to {out_path}")
